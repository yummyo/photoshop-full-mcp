# 受控临时副本渲染

目的：为需要图层效果、蒙版或组内合成的素材提供 `isolated_composite` 模式，并明确记录可验证的范围。当前为已编写、自动化测试通过、尚未实机验收的候选能力；当前安装继续使用已验证的 P1。

## 实现流程

1. 读取原文档状态、文档集合与图层结构，绑定所选图层的索引路径。隐藏目标不会被强制显示；依赖子树外剪贴基础层的目标会拒绝，提示选择包含依赖的组。
2. 在 modal scope 中读取原文档的当前合成像素，用随机名称创建完整临时副本。副本必须是新 ID，不能与任何已有文档相同，名称还必须携带本次随机标识。
3. 立即向 Photoshop 注册副本自动关闭。没有自动关闭支持时，复制前拒绝。原文档不会注册到自动关闭列表。
4. 根据索引路径、名称、类型及整个层级拓扑匹配副本图层；不假设复制前后图层 ID 相同。
5. 仅在副本中隐藏目标子树与祖先链以外的图层，保留目标组内部原有可见性及其 Photoshop 效果、蒙版和组属性，读取前景合成图。
6. 恢复副本的原始可见性，再隐藏目标，读取当前背景。前景、背景和原图都以相同画布、sRGB、8-bit、全分辨率读取。
7. 在前景非透明矩形内计算 source-over 回放误差，使用 alpha 加权的 sRGB 通道值比较，并单独比较 alpha。记录容差、最大差、平均差和不匹配像素数。
8. 副本在 modal scope 退出时自动关闭且不保存。若仍残留，只对经本次随机标识和新 ID 确认归属的副本执行一次清理回退。恢复原活动文档，核对文档集合、源文档状态和源图层可见性/结构。

依据：[Adobe Document.duplicate](https://developer.adobe.com/photoshop/uxp/2022/ps-reference/classes/document) 会创建并激活副本；[Adobe modal 自动关闭机制](https://developer.adobe.com/photoshop/uxp/2022/ps-reference/media/executeasmodal) 可在 modal 结束时关闭已注册的临时文档。此处使用这些接口的实现仍需在本机 Photoshop 验证。

## 校验结果如何解释

- `matched`：在当前背景、素材矩形内，所有被比较像素都在指定容差内。
- `mismatch`：保留 PNG，素材标为 `exported_unverified`，整个设计包标为 partial；不伪装成已通过的独立素材。
- 两种结果都不证明素材在任意新背景上可独立还原，也不证明矩形外的内容不受影响。画布外效果没有导出。
- 比较使用普通 source-over。依赖背景的混合模式、剪贴、父组的复杂合成或字体变化都可能导致不匹配；不会自动改写成“相似”或忽略差异。
- 缺失字体按本轮约定暂缓：相关差异继续记录，PNG 仍可保留检查，不会因此安装或替换字体。

原生侧记录素材像素、原图 ROI 和背景 ROI 的 SHA-256。服务端会重新核对素材像素摘要、校验范围、指标一致性和副本清理状态；导出参考图时，还将原图 ROI 摘要与参考图的实际像素交叉核对，避免使用不同帧的参考图。

## 资源与失败处理

每个副本校验会读取原图、前景和背景三个画布缓冲区。目前只接受整张画布不超过 `max_pixels` 且不超过 400 万像素的 RGB 8-bit 文档。输出仅传回裁切后的前景和校验元数据，不把三个整画布缓冲区全部塞入 MCP 响应。

整批预算按每个隔离素材一个完整画布面积估计，总计上限仍为 1600 万像素。因此 1920×1080 文档一次宜导出少量素材；超限时分批，不自动缩小。

取消时停止整个素材批次。清理不确定时返回 `OUTCOME_UNKNOWN`，保留临时文档 ID，并将运行标为 invalidated；不会继续创建其他副本，更不会为了清理去关闭任何用户原有文档。

## 自动化验证

除既有 P2 测试外，新增覆盖：

- 半透明像素、alpha 边界、当前 ROI 与任意背景的范围区分。
- 副本 ID 变化、组子树可见性、非活动源文档和原选择恢复。
- 错误所有权、拓扑变化、隐藏/剪贴目标与缺少自动关闭能力。
- 用户取消、复制后报错、自动清理失败、有限清理回退和清理不确定时中止。
- 篡改校验回执、不同参考图、局部不匹配保留为未验证素材。

目前相关测试合计 33 项通过，构建通过。没有执行 Photoshop 实机副本创建、素材导出或原 PSD 修改；不能将模拟宿主测试当成真实视觉验收。
